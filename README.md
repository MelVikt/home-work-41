# App.js
Головний компонент, який підключає форму:

```
  <ControlledForm />
```
# ControlledForm
Компонент форми, що дозволяє користувачу вводити повідомлення (Message), 

вибирати країну (Select country через
```
 <CountrySelect />)
 ```
та погоджуватися з умовами (I agree to the terms). 

# CountrySelect

Компонент для завантаження та відображення списку країн.

Логіка запиту:
Запит до API:

```
https://restcountries.com/v3.1/all
```

Дані обробляються та сортуються: виводиться код країни та назва.

# CountryDetails
Компонент для відображення деталей обраної країни.

Запит до API: 
```
https://restcountries.com/v3.1/alpha/${countryCode}, наприклад ${countryCode} = 'Ua' 
```
для отримання даних про країну. Після виводиться прапор, столицю, регіон та населення країни та відображає помилку, якщо дані не вдалося завантажити.
